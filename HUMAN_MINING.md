# Human Mining

**Human Mining means mining human contribution, not machines, attention, or speculation.**

Human Mining is one of the core concepts of XORing O Protocol.

It describes how verified real-human actions, judgments, feedback, and participation can become visible, recordable, and useful in the AI agent era.

---

## 1. What is Human Mining?

Human Mining means discovering, verifying, and recording real human contribution.

It is not about mining machines.

It is not about mining attention.

It is not about mining speculation.

Human Mining is about making real human contribution visible.

A run can be contribution.  
A product review can be contribution.  
A human judgment can be contribution.  
A real-world visit can be contribution.  
A community action can be contribution.  
A feedback signal can be contribution.

---

## 2. Why Human Mining Exists

AI systems are trained on human language, human behavior, human judgment, human culture, and human creativity.

But most human contribution is invisible.

Humans generate value through:

- real actions
- real feedback
- real judgment
- real-world verification
- community building
- product testing
- local participation
- cultural signals
- lived experience

Human Mining exists to make these contributions visible and recordable.

---

## 3. Human Mining vs Machine Mining

Bitcoin introduced machine mining.

Machines performed computational work.  
Networks verified that work.  
Value was created through Proof of Work.

Human Mining explores a different direction.

Humans perform real-world contribution.  
The network verifies that contribution.  
Value is recorded through Proof of Contribution.

```text
Machine Mining
→ Hash Power
→ Proof of Work
→ Network Consensus

Human Mining
→ Real Human Action
→ Proof of Contribution
→ Human Value Record
```

## 7. Human Mining and Privacy

Human Mining should not become surveillance.

It should follow these principles:

### Minimal Proof

Only record necessary proof.

For example:

```text
activity_verified: true
```

is better than exposing full raw activity data.

### User Consent

Users should know when they are contributing.

### Purpose Limitation

Contribution data should not be reused for unrelated purposes without permission.

### No Hidden Extraction

Human contribution should not be silently extracted.

Users should be visible as contributors.
