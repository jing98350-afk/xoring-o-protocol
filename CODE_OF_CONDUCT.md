# Code of Conduct

XORing O Protocol is an open discussion space for exploring verified real-human presence, Proof of Contribution, AIOS contribution records, Human Mining, and real-human communities.

We welcome contributors from different backgrounds, including developers, researchers, designers, community builders, translators, and protocol thinkers.

This Code of Conduct exists to keep the project clear, constructive, and safe for open contribution.

---

## 1. Expected Behavior

Contributors are expected to:

- communicate respectfully
- discuss ideas, not attack people
- provide specific feedback
- explain reasoning when proposing changes
- respect privacy and compliance concerns
- avoid misleading claims
- avoid financial promotion
- keep discussions focused on the protocol

---

## 2. Unacceptable Behavior

The following behavior is not acceptable:

- harassment
- personal attacks
- threats
- hate speech
- spam
- scams
- misleading financial claims
- guaranteed return claims
- gambling promotion
- speculative investment promotion
- exposing private or sensitive data
- repeatedly derailing discussions

---

## 3. Discussion Standards

Please keep discussions:

- clear
- specific
- evidence-based
- relevant to XORing O Protocol
- aware of privacy risks
- aware of compliance risks
- focused on verified human presence and contribution

Low-quality hype, vague promotion, or unsupported claims may be removed.

---

## 4. Financial and Compliance Language

XORing O Protocol should be discussed as a protocol for verified human presence and contribution records.

Please avoid wording such as:

- guaranteed income
- passive yield
- staking return
- investment opportunity
- profit sharing
- financial freedom
- gambling
- speculation

Preferred wording includes:

- contribution record
- verified human presence
- Proof of Contribution
- O State
- Human Mining
- service access
- task participation
- identity growth
- community contribution
- privacy-preserving proof

---

## 5. Privacy Standards

Contributors should avoid requesting, exposing, or encouraging unnecessary sharing of raw biometric or personal data.

The protocol should prioritize:

- minimal proof
- user consent
- purpose limitation
- privacy-preserving verification
- no hidden data extraction

For example:

```text
heartbeat_verified: true
```

is better than exposing full raw heart-rate data.

---

## 6. Enforcement

Project maintainers may take action when behavior violates this Code of Conduct.

Possible actions include:

- asking for clarification
- editing or removing inappropriate content
- closing issues or discussions
- limiting participation
- blocking contributors in serious cases

Enforcement should focus on maintaining a constructive protocol discussion environment.

---

## 7. Scope

This Code of Conduct applies to:

- GitHub Issues
- GitHub Discussions
- Pull Requests
- documentation contributions
- translation contributions
- public project discussions linked to XORing O Protocol

---

## 8. Final Note

XORing O Protocol is an early public draft.

We invite open debate, disagreement, and critical feedback.

The goal is not to create hype.

The goal is to define a clearer protocol direction for real-human presence and human contribution in the AI agent era.
