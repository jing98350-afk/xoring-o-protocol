# Roadmap

**XORing O Protocol is an early public draft.**

This roadmap describes the possible development path of O State, Proof of Contribution, AIOS, Human Mining, and real-human communities.

The roadmap is not fixed.

It should evolve through public discussion, community feedback, and protocol contribution.

---

## Phase 1: Protocol Draft

Goal:

Publish the first public draft of XORing O Protocol.

Core tasks:

- publish README
- publish whitepaper
- define O State
- define Proof of Contribution
- define AIOS contribution record
- define Human Mining
- define privacy principles
- define compliance principles
- open GitHub Issues
- open GitHub Discussions

Main output:

```text
Public protocol draft
→ GitHub repository
→ Community feedback
→ Open questions
```

## Phase 10: Long-Term Direction

Long-term possibilities include:

- verified real-human communities
- anti-bot human presence layer
- AI feedback networks
- merchant task networks
- city node networks
- verified human events
- real-world contribution reputation
- third-party O State integrations
- privacy-preserving human proof
- human contribution infrastructure for the AI era

The final goal is not only to build a smart ring.

The goal is to explore a real-human presence layer for the AI agent era.
